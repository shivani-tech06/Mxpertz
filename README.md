Inventory Management System

This is a simple Inventory Management System for a small retail store built using Spring Boot and MySQL.

The system allows users to:

1. Add products to the inventory
2. Update product quantities
3. Remove products from the inventory
4. View all products in the inventory

Tech Stack:
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

How to Run:

1. Create a MySQL database:
   CREATE DATABASE inventory_db;

2. Update database configuration in application.properties.

3. Run the main class:
   InventoryManagementApplication.java

4. Use Postman to test the APIs.
